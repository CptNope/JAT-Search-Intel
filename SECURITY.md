# Security Policy

## Supported versions

Security fixes go into the latest release. Please update to it before reporting.

| Version | Supported |
| ------- | --------- |
| 3.5.x   | Yes       |
| < 3.5   | No        |

## Reporting a vulnerability

Please **do not** open a public issue for a security problem.

Report it privately through GitHub instead: open the
[**Security** tab of this repository](https://github.com/CptNope/JAT-Search-Intel/security)
and choose **Report a vulnerability**. You can also email
info@jeremyanderson.tech with "JAT Search Intel security" in the subject.

Please include:

- the plugin version and your WordPress and PHP versions
- what an attacker can do, and which user role (if any) they need
- steps or a proof of concept to reproduce it

You will get a reply within 3 working days. Once a fix is ready we publish a
release and a GitHub security advisory, and credit you unless you prefer not.

The plugin is also covered by the
[WordPress.org plugin security process](https://developer.wordpress.org/plugins/wordpress-org/plugin-security/).
